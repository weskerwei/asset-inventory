# 財產盤點 App

這是一個純前端的網頁 App（PWA），手機與電腦都能用。財產資料和盤點紀錄只存在各裝置的瀏覽器裡，**不會上傳到任何伺服器**。

## 檔案
- `index.html`：App 主程式
- `sw.js`、`manifest.webmanifest`、`icon-*.png`：離線使用與「加入主畫面」用
- `vendor/`：開源套件（SheetJS 讀寫 Excel、qrcode-generator、JsBarcode、html5-qrcode 相機掃描）

## 上線方式
手機相機只能在 **HTTPS** 網址下使用，所以要把整個資料夾放到任一 HTTPS 靜態網站空間：
- 公司內部的 HTTPS 網站伺服器（IIS / Nginx 等）
- GitHub Pages、Netlify、Cloudflare Pages（免費）。只會放程式，財產資料不會在上面

上線後用手機開啟網址：
- iPhone：Safari →「分享」→「加入主畫面」
- Android：Chrome →「⋮」→「安裝應用程式」

裝好後沒有網路也能開啟和盤點。

## 在電腦上本機測試
```
python -m http.server 8765
```
然後開啟 http://localhost:8765

## 使用流程
1. **設定 → 匯入財產清冊**：可以直接匯入會計系統產出的「財產目錄清冊」（多個工作表都會讀入）
2. **部門**：清冊沒有部門欄時，到「設定 → 下載財產清單（含部門欄）」填好部門再匯入；也可以在「清單」頁逐筆或批次設定
3. **標籤 → 列印標籤**：支援標籤機（50×30、60×40、40×25 mm）和 A4 標籤貼紙
   - 可以依部門、類別、標籤狀態（未列印／未黏貼）或編號區間（起～迄）列印；「指定編號」欄也能寫 `A202412001~A202412050`
   - 列印後確認「已列印」，App 就會記錄列印時間
   - 黏貼後，到「掃描」頁切換為「**標籤黏貼確認**」模式掃描標籤，記錄黏貼確認；這不會記成盤點
   - 「標籤」頁會統計各部門的應貼、已印、已貼、未貼，也能匯出「標籤作業紀錄」Excel
4. **掃描**：一定要先填寫「盤點人」姓名才能盤點，再開啟相機連續掃描。不同狀況有不同提示音：已盤點、重複掃描、清冊外條碼
5. **總覽**：可以即時看到各部門／資產類別的已盤與未盤數量
6. **匯出 Excel**：包含摘要、部門統計、類別統計、盤點明細、已盤點、未盤點、清冊外條碼等工作表
7. 多人分頭盤點時，每支手機各自「匯出盤點紀錄備份」，再到主要裝置「匯入合併備份」
